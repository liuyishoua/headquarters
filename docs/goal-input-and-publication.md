# 缺失输入与发布准备

规划动作增加 `request_input`，参数包含一个具体问题和缺失字段列表。动作保存可读阻塞原因并停止目标推进；用户补充反馈仅恢复这类输入阻塞，不恢复未知社交写入。准备草稿与读取素材应在请求信息之前完成。

连续三次 wait，且期间没有新的用户/执行反馈或资源观察，会转为输入阻塞，防止消耗预算反复等待。异步业务任务仍由已有 pending 收据轮询，不以空等替代实际结果。

闲鱼商品读取现在包含账号隔离的草稿/素材/地点准备信息，草稿字段可分步保存。新的发布阶段记录可区分未提交最终商品的准备失败与最终请求后的未知结果；旧 unknown 不据重现伪造结论。未知行动保持 blocked，不自动重复发布。

对应回归覆盖：明确输入阻塞、用户反馈恢复、重复 wait 停止；闲鱼覆盖素材隔离、可保存未完成草稿、准备失败与最终超时区分、持久化阶段顺序、无需邮寄不虚构地点和未知请求不重试。
